# PID_SimLab v0.1

**基于 Python 的 PID 控制系统仿真、参数整定与性能对比可视化平台**

> 当前版本定位：**每个功能页先跑通一个可演示的基础功能**，验证整套算法链路与界面骨架没问题，
> 后续再按功能页逐个深化（见文末「迭代路线」）。

## 一、运行方法

```bash
cd PID_SimLab
pip install -r requirements.txt      # Anaconda 环境通常只需补 streamlit / plotly / openpyxl
streamlit run app.py
```

Windows 下有两个一键入口（推荐用法）：

| 文件 | 作用 |
| --- | --- |
| **`用Edge打开.bat`** | 自动检查/启动仿真服务，等待就绪后用 **Edge** 打开 `http://localhost:8501`（推荐） |
| `启动程序.bat` | 只启动服务，自己用任意浏览器访问 `http://localhost:8501` |

> 常见问题：`localhost:8501/_stcore/health` 是**健康检查端点**（只返回 `ok`），不是程序页面。
> 正确地址是 **`http://localhost:8501`**（不要带 `/_stcore/health`）。

命令行自检（不依赖界面，验证算法正确性）：

```bash
python selftest.py
```

   ```

   手机访问 : http://192.168.x.x:8501     ← 脚本自动识别当前 IP
   ```
2. 手机连上**与电脑同一个 Wi-Fi**，浏览器打开那个"手机访问"地址即可。

### 首次使用需要放行防火墙（只需做一次）

用**管理员身份**打开 PowerShell 或 CMD，执行：

```bat
netsh advfirewall firewall add rule name="PID_SimLab 8501" dir=in action=allow protocol=TCP localport=8501
```

图形界面方式：控制面板 → Windows Defender 防火墙 → 高级设置 → 入站规则 → 新建规则 →
端口 → TCP → 特定本地端口 `8501` → 允许连接 → 三个配置文件都勾选 → 命名保存。

### 打不开时按顺序排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 电脑能开、手机转圈超时 | 防火墙拦了 | 执行上面的放行命令 |
| 手机提示无法访问 | 不在同一 Wi-Fi | 检查手机是否连了同一路由器 |
| 同一 Wi-Fi 仍连不上 | 网络开了**客户端隔离**（校园网/公司网常见） | 用手机热点组网测试；或改用公网部署 |
| 昨天能开今天不行 | IP 变了（DHCP） | 重新双击 bat，它会重新识别 IP |

> ⚠️ 服务运行期间，**同一局域网内的其他设备也能访问**（无密码）。本平台只是仿真工具、不含隐私数据，但请勿在公共网络上长期开着。

### 如果想在"不同网络"下也能访问

局域网方案要求手机和电脑在同一 Wi-Fi。若要在外面（4G/其他网络）访问，需要：

- **公网部署**：把代码推送到 GitHub，再用 Streamlit Community Cloud 等平台部署（免费、有公网地址）；
- **内网穿透**：在电脑上装 ngrok / Cloudflare Tunnel，把 8501 端口映射成公网地址。

两者都需要额外安装工具并联网，按需选择。

## 二·补、对象模型库（v0.2 新增）

平台不再局限于二阶对象。左侧「对象模型库」内置 5 种典型对象，并支持自定义传递函数：

| 模型 | 传递函数 | 教学意义 |
| --- | --- | --- |
| 标准二阶对象 | K·ωn² / (s² + 2ζωn·s + ωn²) · e^(−τs) | 与解析公式逐项对照，验证仿真内核 |
| 一阶惯性对象 | K / (T·s + 1) · e^(−τs) | 0 型系统：对阶跃输入有静差，说明纯 P 为何消不掉差 |
| 带积分对象 | K / [s·(T·s + 1)] · e^(−τs) | Ⅰ 型系统：自身含积分环节，阶跃输入理论上无静差 |
| 三阶惯性对象 | K / [(T₁s+1)(T₂s+1)(T₃s+1)] · e^(−τs) | 高阶对象：相角更易穿越 −180°，ZN 临界比例度法天然可用 |
| 非最小相位对象 | K·(1 − Tz·s) / [(T₁s+1)(T₂s+1)] · e^(−τs) | 含右半平面零点：起始反向响应，经典控制难点 |
| 自定义传递函数 | 任意 num(s)/den(s) · e^(−τs) | 直接输入降幂系数，例如 num = 1, 2　den = 1, 3, 2 |

统一由 `LTIPlant` 基类承载，提供状态空间、频率特性、零极点、稳定判据等接口，
仿真 / 整定 / 绘图 / 抗扰 / 非线性五个功能页**全部自动支持任意阶次对象**。
非真传递函数（分子阶次高于分母）会被自动拒绝并给出提示。

## 二·补二、改进型 PID（三项工程改进）

在标准 PID 上叠加三项工程上最常用的改进，并可逐项对比效果：

| 改进 | 做法 | 解决的问题 | 实测效果（默认工况） |
| --- | --- | --- | --- |
| **积分分离** | \|e\| > ε 时切除积分项并冻结积分器，小偏差时恢复 | 大偏差时积分饱和 → 巨大退饱和超调 | 大阶跃下峰值 **1857 → 5.57**，σ **197% → 39%** |
| **不完全微分** | 微分项串一阶惯性环节，Tf = Td/N；关闭即为完全微分 | 理想微分放大高频噪声 → 执行器高频抖动 | 噪声下控制量总变差 **降低 62%**，跟踪指标基本不变 |
| **抗积分饱和** | 反算法 / 条件积分 / 积分限幅三种方案可选 | 执行器饱和时积分器无限累积 | σ **16.3% → 8.1% / 7.7% / 10.3%** |

配套新增指标：**控制量总变差 TV = Σ\|u(k+1) − u(k)\|**，用来定量衡量微分形式对执行器的影响，
而不是只靠"看起来更平滑"这种定性描述。仿真内核还支持**量测噪声注入**（控制器看到含噪量测，指标仍按真值计算）。

> 注意：三项改进**并非线性叠加**。实测中"三项全开"的超调可能反而高于单项最优，
> 因为积分分离冻结积分后，抗饱和的作用空间变小，两者存在耦合。这本身就是一个值得在论文里讨论的现象。

## 四、核心算法说明

### 1. 时域仿真内核

对象统一写成状态空间可控标准型，并对矩阵指数做**零阶保持精确离散化**，对线性对象没有离散化误差：

```
x(k+1) = Ad·x(k) + Bd·u(k)
Ad = e^(A·dt),   Bd = A⁻¹(Ad − I)B   （用增广矩阵指数一次算得，避免求逆）
```

纯滞后 τ 用「输入历史缓冲 + 线性插值」实现，允许 τ 不是步长整数倍。
PID 采用并联式，微分项**对量测微分**（避免给定值跳变的微分冲击），并加一阶低通滤波 `Tf = Td/N`。
抗积分饱和采用**反算法**：`I ← I + (u_sat − u_raw)/Ki`（只针对饱和非线性补偿）。

### 2. 性能指标

超调量 σ%、峰值时间 tp、上升时间（10%–90% 与 0–100% 两种定义）、调节时间 ts(2%/5%)、
稳态误差 ess、误差积分指标 IAE / ISE / ITAE、衰减比 δ。

二阶系统的理论公式（用于仿真核验）：

```
σ% = e^(−πζ/√(1−ζ²)) × 100%
tp = π/ωd,   ωd = ωn√(1−ζ²)
tr(0→100%) = (π − arccos ζ)/ωd
ts 包络上界 = −ln(Δ)/(ζωn)，工程近似 3/(ζωn) (2%)、4/(ζωn) (5%)
```

### 3. 三种经典整定算法

**① Z-N 临界比例度法（闭环振荡法）**：令开环频率特性相角穿越 −180°，解出临界频率 ωu，
则 Ku = 1/|G(jωu)|、Pu = 2π/ωu，再套经验公式。

| 模式 | Kp | Ti | Td |
| --- | --- | --- | --- |
| P | 0.5 Ku | — | — |
| PI | 0.45 Ku | Pu/1.2 | — |
| PD | 0.8 Ku | — | Pu/8 |
| PID | 0.6 Ku | Pu/2 | Pu/8 |

**② Z-N 阶跃响应法（开环反应曲线法）**：用最大斜率切线法把对象辨识为一阶惯性加纯滞后
K/(Ts+1)·e^(−Ls)，再整定：P 用 T/(K·L)；(PI) 0.9T/(K·L), Ti=L/0.3；(PID) 1.2T/(K·L), Ti=2L, Td=0.5L。

**③ 衰减曲线法**：数值搜索使闭环纯比例控制达到 4:1（或 10:1）衰减比的 Kc，并测得振荡周期 Ts，
再套经验公式。4:1 时 PID 取 `Kp=0.8Kc, Ti=0.3Ts, Td=0.1Ts`。

> ⚠️ 注意：纯二阶无滞后系统的相角只渐近趋于 −180°、不穿越，**Z-N 临界比例度法在数学上不适用**
> （程序会给出提示）。加入纯滞后 τ>0 后即可求解，这也是程序默认 τ=0.1 s 的原因。

## 四·补、频域分析与稳定性判据

以开环频率特性 `L(jω) = C(jω)·G(jω)` 为基础，三种方法互相印证：

| 方法 | 公式 | 输出 |
| --- | --- | --- |
| 稳定裕度 | 幅值裕度 h = 1/\|L(jω_pc)\|，h_dB = −20lg\|L(jω_pc)\|（∠L = −180°）<br>相位裕度 γ = 180° + ∠L(jω_gc)（\|L\| = 1） | GM、PM、ωgc、ωpc 与裕度分级（良好/合格/临界/不稳定） |
| Nyquist 判据 | **Z = P − N**：P 开环右半平面极点数，N 绕 (−1, j0) 的净逆时针圈数，Z 闭环右半平面极点数 | Nyquist 曲线、绕数与 Z 值，并**自动与直接求闭环极点互验** |
| 根轨迹 | 1 + k·L(s) = 0 ⇒ den_L(s) + k·num_L(s) = 0，k = 1 即当前参数 | 闭环极点随开环增益 k 的移动轨迹 |

要点：

- 纯滞后用**一阶 Padé 近似** `e^(−τs) ≈ (1 − τs/2)/(1 + τs/2)` 计入，使根轨迹与 Nyquist 判据可用；
- 原点处积分环节的**零极点对消**已正确处理（P/PD 控制器的 s/s 不计为积分环节），Nyquist 绕数按原点绕行小圆弧修正；
- 平台自动执行**三重一致性校验**：Bode 裕度判定、Nyquist 的 Z = P − N、根轨迹中极点是否越过虚轴，结论必须一致；
- 自检中用一个解析可验证的算例 `L = 2/(s+1)³` 核对：ωpc = √3、h = 12.041 dB、γ = 67.598°，仿真值与解析值完全吻合。

## 六、技术要点与常见提问

1. **仿真内核可被信任**：标准二阶对象把仿真结果与解析公式并列对照，误差 < 0.5%。
2. **三种整定算法有对比维度**：ZN 法激进、衰减曲线法折中、数值寻优针对性强。
3. **抗干扰用定量指标评价**：最大动态偏差、恢复时间、扰动后 IAE，避免只画曲线不定量。
4. **非线性的数学处理**：用描述函数 N(A) 把死区/饱和近似为幅值相关的等效增益，再用 Nyquist 判据分析极限环。
5. **数据可核对、可保存**：所有曲线数据与性能指标表都在界面中完整展示，并可保存为 CSV / Excel / PNG / ZIP。
